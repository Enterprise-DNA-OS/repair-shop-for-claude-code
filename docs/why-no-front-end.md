# Why there is no front end

This is a repair records system with a command line and coding-agent recipes. It produces read-only HTML views and printable documents. No application server is required.

A counter screen gives quick scanning, signatures, photos, card terminals, offline intake and customer self-service. This base does not provide those features. Keep the existing counter POS and payment terminal. Enterprise DNA can scope counter screens and connections around the owned database.

The local database accepts one process at a time. For a team use a private shared database with operator roles, backups and network controls configured by its owner. There is no built-in web login or tenant boundary. Generated files and exports contain customer data and must stay private.
