# Make this shop yours

Read CLAUDE.md and the current migrations. Ask which field, stage or internal rule the operator wants changed. Inspect the records first. Write the change as a new numbered migration; never rewrite an applied migration. Update the CLI, relevant views, documents and recipes. Keep statutory notice checks separate from internal thresholds. Apply with npm run migrate, run npm test, and show the changed result. Back up a real database before applying structural changes. Never turn a request for customisation into a send or payment action.
